## IP信誉检测到底在检测什么？

一句话：查这个IP的“前科”和“出身”。前科是它有没有被记录过发垃圾邮件、扫描攻击、欺诈流量这类行为；出身是它属于住宅宽带、机房，还是Tor、VPN这类匿名网络的出口。

市面上检测服务的输出大体分两类分数。**信任分**回答的问题是“这个IP背后像不像有个正常人”：机房出口、数据中心段、匿名网络节点，信任分天然就低。**欺诈分**回答的是另一个问题：“这个IP有没有被记录过干坏事”。两个问题都合理，但答案经常对不上——最典型的例子是8.8.8.8：它是Google的公共DNS，背后没有“人”，信任分不会高；但它也从没干过坏事，欺诈分是干净的0。

除了分数，多数服务还会给一组标记：是否机房（hosting）、是否代理（proxy）、是否VPN、是否Tor出口、是否被记录过滥用（abuser）。这些布尔标记往往比分数本身更好用，后面会讲为什么。

## 分数怎么读，才不会被带偏

拿到分数先问两个问题：方向是什么，以及它在回答哪个问题。

方向好办：信任分越高越好，欺诈分越高越糟。容易忽略的是后半句——两套分数方向相反，跨服务比大小毫无意义。

“回答哪个问题”更关键。机房标记是网络属性，8个测试IP里凡属机房的全带hosting标记。1.1.1.1信任分只有41被判poor，欺诈分却是0——它只是背后没有正常人，不等于它坏。反过来也有：DigitalOcean那台主机信任分76被判good，欺诈分却拿到50。真正值得你停下手的信号是Tor、abuser这类行为标记，它们直接告诉你这台机器被记录过什么，比一个孤零零的数字更可操作。

### 为什么不同网站的检测结果差别这么大？

因为它们的数据源、算法和分数定义全都不一样。实测里两套主流分数的秩相关只有-0.05，连“分数高低代表什么”都互相相反。

### 分数多少算差？

没有跨服务的统一标准。有意义的是同一家服务内部的前后对比：比如换IP前后各测一次，或者同一批IP互相比较。
